# Project Adoption

Read [documentation.md](documentation.md) before creating or changing a
project-level README, design document, decision record, or local ledger.

Use [templates](templates/) as a starting point for a solution repository. Do
not copy cross-project coding, dependency, testing, or security rules into a
project document; link to the adopted knowledge-base revision instead.

When the task concerns C#, packages, tests, or runtime behavior, also route to
the applicable `.NET` standards through the root `development-standards` Skill.
