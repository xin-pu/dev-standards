# Project Improvements Ledger

Use this ledger for project-specific improvements, risks, and operational
follow-ups. Promote a reusable lesson to the shared development-standards
improvement ledger instead of copying a shared rule here.

## Statuses

`Open`, `Monitoring`, `Implemented`, `Deferred`, or `Closed`.

## Entries

No project improvements recorded.

## Template

```markdown
### PL-YYYY-NNN - Short outcome-oriented title

- **Status:** Open
- **Recorded on:** YYYY-MM-DD
- **Scope:** Affected component, workflow, or operation.
- **Observation:** Problem, opportunity, or risk.
- **Decision or next step:** Concrete action or reason to defer.
- **Evidence:** Issue, PR, incident, test, or investigation link.
- **Owner:** Accountable person or role.
- **Review again:** YYYY-MM-DD or `not needed`.
```
